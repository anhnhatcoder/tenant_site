Xác Thực Webhook (Authorization: Bearer)

Bắt buộc bên phát (HC TECH IoT Platform, ChirpStack v4) phải gửi kèm Header Bearer token để bảo vệ Webhook

Đã Bật Xác Thực Bearer
BEARER

Token được lưu vĩnh viễn và có hiệu lực ngay lập tức (không cần restart máy chủ).

Cấu hình mẫu trên cổng phát (HC TECH Platform / ChirpStack Gateway):
Header Name : Authorization
Header Value: Bearer {{ webhook_bearer_token }}
* Tương thích ngược: Hệ thống cũng chấp nhận Header X-Webhook-Secret: {{ webhook_bearer_token }}
